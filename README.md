# ZéGelado Docs

Portal público de conhecimento do ZéGelado, publicado em:

<https://zorvexa-digital.github.io/zegelado-docs/>

## Desenvolvimento

```bash
npm ci
npm run dev
```

## Validação

```bash
npm run build
```

O conteúdo público é exportado do projeto principal por uma lista explícita. Documentos internos e código da aplicação não pertencem a este repositório.

## Dependência

O VitePress `2.0.0-alpha.20` permanece fixado no lockfile. Por ser uma versão alpha, atualizações exigem nova validação de build, navegação e busca; a migração para uma versão estável corrigida permanece recomendada quando disponível.
